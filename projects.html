Memora Store

CEO & Founder · Full-Stack Developer

Memora is a digital wedding invitation platform and online store that I founded and built from the ground up. I personally design and create all the invitation products offered through the platform.

Project Overview

Memora is my own business — a digital wedding invitation platform and online store. The platform allows customers to browse a curated collection of wedding invitation products and bundles, preview live interactive demos of each invitation, and place orders through a structured e-commerce flow. I designed the business model, created the invitation products, developed the entire platform, and handle all customer operations.

Problem & Solution

The Problem

Couples looking for digital wedding invitations face either generic templates that lack personality or expensive custom design services with long turnaround times. There was no unified platform for browsing, previewing live demos, and ordering custom invitations with direct creator communication.

The Solution

I built Memora as an end-to-end e-commerce platform for digital wedding invitations. Customers browse products or bundles, see exactly what they're getting through live interactive demos, and complete their order through a guided step-by-step flow with InstaPay payment and WhatsApp communication.

Key Features

E-commerce store with individual products and curated bundles
Live interactive invitation demos customers can preview before purchase
Structured 7-step ordering flow with input validation
InstaPay payment link integration
Automated WhatsApp order link generation for direct communication
Product categorization, filtering, and detailed product pages

How the System Works

Customers follow a structured purchasing flow from discovery to order confirmation:

Browse→ Choose Product / Bundle→ Live Demo→ Start Your Order→ Enter Details→ Payment→ Order Confirmed

Technologies Used

HTMLCSSJavaScriptSupabaseVercel

Important Technical Details

Supabase serves as the backend database for products, bundles, orders, and customer data. The ordering flow is a multi-step form that validates input at each step and generates a final order record in the database. InstaPay payment links are dynamically generated based on the order total, and WhatsApp links are constructed with pre-filled order details so I can communicate directly with each customer. Live demos load actual invitation templates with sample data so customers see exactly what they'll receive. The platform is deployed on Vercel for fast, reliable hosting with automatic deployments from the repository.

Challenges / What I Solved

Built a complete e-commerce flow as a solo developer — from product display to payment and order management
Designed a multi-step ordering process that guides customers without overwhelming them
Integrated third-party communication (WhatsApp) and payment (InstaPay) into a seamless experience
Created a flexible product/bundle system to handle different invitation types and pricing

Results / Purpose

The platform is live and serving real customers, handling the full lifecycle from product browsing to order completion and customer communication. As the founder, I continue to design new invitation products and manage all business operations through the companion admin dashboard.

Full-Stack Developer

The management system I built to run the entire Memora business from a single interface — from tracking orders and analyzing sales to managing products and communicating with customers.

Project Overview

The Memora Admin Dashboard is the backend management system for the Memora business. It provides comprehensive tools for tracking orders, analyzing sales performance, managing products and bundles, adjusting pricing, and communicating directly with customers — all from one centralized interface.

Problem & Solution

The Problem

As Memora grew, managing orders, products, and customer communication through separate tools became inefficient. I needed a centralized system with real-time visibility into every aspect of the business without switching between multiple platforms.

The Solution

I designed and built a custom admin dashboard tailored specifically to Memora's operations. The dashboard consolidates order management, product catalog control, pricing adjustments, sales analytics, and customer communication into one unified interface.

Key Features

Order analytics and tracking dashboard with real-time data
Full product management — add, edit, remove products with images
Bundle creation and management system
Dynamic pricing control across all products and bundles
Detailed customer order view with complete order history
WhatsApp direct message integration per order for instant communication

How the System Works

The admin dashboard provides a complete management workflow:

Dashboard Overview→ Orders→ Products→ Bundles→ Analytics→ Customer Communication

Technologies Used

HTMLCSSJavaScriptSupabaseVercel

RingRoad CRM

Full-Stack Developer

A complete Customer Relationship Management system I built for Ring Road Real Estate to centralize client management, track deals, and streamline sales operations.

Project Overview

I developed a complete CRM system for Ring Road Real Estate. The platform provides a centralized hub for managing clients, tracking property deals through a pipeline, scheduling follow-ups with calendar integration, running outbound sales through a TeleSales module, and monitoring overall sales performance through an analytics dashboard.

Problem & Solution

The Problem

The real estate company's client information was scattered across different tools. Follow-ups were being missed, there was no clear view of the sales pipeline, and management had no centralized way to monitor team performance or deal progress.

The Solution

I built a custom CRM designed around real estate workflows — centralizing all client data, tracking deals through pipeline stages, automating follow-up reminders with calendar integration, and providing analytics dashboards for management oversight.

My Role

I served as the sole developer on this project. I designed the system architecture, built all frontend and backend components, structured the database, and deployed the application. I worked closely with the business team to understand their sales workflow and translated their requirements into a functional CRM system.

Key Features

Client management with status tracking, filtering, and detailed contact records
Deal pipeline with stage-based progression and status updates
Follow-up scheduling with calendar integration and reminders
TeleSales module for organizing outbound sales workflows
Property listing management with detailed property records
Analytics dashboard with performance metrics and reporting
Sold properties tracking with completion records
Advanced search and multi-criteria filtering

How the System Works

The CRM follows the real estate sales cycle from lead acquisition to closing:

Dashboard→ Clients→ Properties→ Deals→ Follow-Ups→ TeleSales→ Analytics

Important Technical Details

Client records support status-based filtering to quickly identify prospects, active clients, and closed deals. The deal pipeline tracks each interaction through defined stages with status updates, giving the team visibility into where every deal stands. Calendar integration links follow-ups to specific dates with reminder functionality so no client interaction is missed. The TeleSales module organizes outbound call workflows and tracks outcomes, while the analytics dashboard aggregates data across clients, deals, and sales activity to provide management with actionable insights.

Challenges / What I Solved

Designed a data model flexible enough to represent the full real estate sales cycle
Built an intuitive interface that sales agents could adopt without extensive training
Implemented a follow-up system with calendar views that prevents missed client interactions
Created analytics that give management visibility into individual and team performance

Results / Purpose

The CRM is deployed and used by the Ring Road Real Estate team for daily client management and sales operations. It replaced scattered tools with a single unified platform, giving the team a clear view of their pipeline and ensuring consistent follow-up with every client.

RingRoad Attendance

Full-Stack Developer

A web-based attendance management system I developed for Ring Road Real Estate, featuring GPS-verified clock in/out, a tiered leave management system, and a comprehensive admin dashboard.

Project Overview

I developed a web-based attendance management system that uses GPS verification to ensure employees can only clock in and out when physically present at the company location. The system includes a complete leave management workflow with tiered approval rules, automatic working hours calculation, a notification system, and a comprehensive admin dashboard for workforce monitoring and reporting.

Problem & Solution

The Problem

The company needed a reliable way to verify employee attendance at the office — not just trust-based manual check-ins. They also needed structured leave management with clear rules around schedule changes, and administrators needed real-time visibility into workforce data.

The Solution

I built a system that uses the browser's Geolocation API to verify the employee's physical location before allowing clock in or clock out — enforcing a 150-meter radius boundary. The system also includes leave balance tracking, a request workflow with tiered approval rules, and a full admin dashboard with reports.

My Role

I served as the sole developer. I designed the location verification logic, built the complete attendance and leave management systems, implemented the authentication flow using Supabase Auth, and developed the admin dashboard with reporting tools.

Key Features

Location-based clock in/out with GPS coordinate verification
150-meter company radius boundary enforcement
Automatic working hours calculation from timestamps
Real-time attendance status tracking across the workforce
Leave request management with remaining balance tracking
Tiered leave-change approval rules (1st free, 2nd needs approval, 3rd blocked)
Notification system for approvals, alerts, and status changes
Secure authentication for employees and administrators
Admin dashboard with attendance reports and employee management
Weekend/day-off scheduling and change management

How the System Works

For Employees:

Login→ Clock In (GPS verified)→ Work→ Clock Out (GPS verified)→ Hours Calculated

For Leave Requests:

Submit Request→ Check Balance→ Approval Workflow→ Balance Updated

For Administrators:

Dashboard→ Monitor Attendance→ Manage Employees→ Review Requests→ Reports

Leave Management Rules

I implemented leave-day change rules to maintain a controlled and transparent process:

1stFirst ChangeNo approval needed
2ndSecond ChangeRequires admin approval
3rdThird ChangeNot allowed

Technologies Used

HTMLCSSJavaScriptSupabaseSupabase AuthVercel

Important Technical Details

The system uses the browser's Geolocation API to capture the employee's coordinates, then calculates the distance to the company location using the Haversine formula to verify they're within the 150-meter radius. Supabase Auth handles secure authentication for both employees and administrators with role-based access control. Working hours are calculated from clock-in and clock-out timestamps, with logic to handle edge cases like missed clock-outs. The leave management system tracks each employee's balance and enforces the 3-tier approval workflow programmatically. Real-time attendance status updates allow administrators to see who is currently clocked in at any moment. The notification system alerts administrators to pending leave requests and employees to approval decisions.

Challenges / What I Solved

Implemented reliable GPS verification across different browsers and devices, with error handling for denied location permissions
Designed the 3-tier leave approval workflow with business rules that prevent abuse while maintaining flexibility
Built a system that handles real-world edge cases: missed clock-outs, GPS signal variations, multiple clock-in attempts
Created an admin dashboard that provides actionable workforce insights without overwhelming administrators

Results / Purpose

The attendance system is deployed and used daily by Ring Road Real Estate employees. The GPS verification ensures accurate attendance records without relying on trust-based check-ins. The leave management workflow provides a transparent and controlled process for schedule changes. The admin dashboard gives management complete visibility into workforce patterns and attendance data.
